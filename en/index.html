ROBOT MOTION · Quadruped robot

Your robot design
walks in virtual space

We modeled a quadruped robot in 3D with MakerCAD and linked it to a motion program. Motor control and the 3D model move together, so you can watch it walk virtually before powering on the real robot.

  1. Robot designDesign body, legs and brackets in 3D and assemble with servos
  2. Motion creationSave poses to create walk, turn and greeting motions
  3. Motor controlAssign a motor ID to each joint and control it with AX servo values (0–1023)
  4. Virtual walking simulationWatch the 3D model walk across the floor like the real thing

MakerCAD robot motion screen · stand, walk forward/back, turn left/right, greet (31 s)

  • Left-right mirroring · front/back leg copy

  • Connect real robots via USB · Bluetooth

CERTIFICATE TUTORIAL · 3D Printer Operation Craftsman

3D Printer Operation Craftsman practical exam,
step by step with tutorials

Practice in the exact order of the published exam tasks. Read the drawing, model and assemble parts in MakerCAD, save as STP·STL, then learn slicing, printing and post-processing in one go.

Task 13D modeling
  1. Reading drawings · Part modelingDraw parts at 1:1 scale per the drawing. Set fit clearances for moving parts, and engraveyour candidate number at the specified spot.Check: within ±1 mm of reference dimensions
  2. Assembly · Saving filesAssemble parts 1:1 exactly as shown in the drawing and save as STP and STL. File name = candidate number (e.g. 02.STP).Check: graded on the STP file
  3. SlicingSlice the assembly for the exam-site printer model and have the estimated print time confirmed.Check: estimated print time within 1 h 20 min
Task 23D printing
  1. Printer setupClean the nozzle and bed, inspect the PLA filament, then level the bed.Check: no sample test prints
  2. OutputLoad the print file via USB·SD card, set the parameters, and print the 1:1 assembly.Check: no wireless transfer
  3. Post-processing · CleanupRemove supports and burrs before submitting, and restore the printer to its pre-exam state.Check: wear gloves · dust mask
Final check to avoid disqualification and deductions
  • Missing, embossed or misplaced candidate number
  • 1:1 scale and assembled state
  • Dimensional error over ±2 mm
  • Missing STP file
  • Out-of-range movement
  • Supports left on · Damage

Based on the HRD Korea published tasks for 3D Printer Operation Craftsman. Always check the latest published tasks before the exam.
