ROBOT MOTION · 4족 보행로봇

설계한 로봇이
가상공간에서 걷습니다

메이커캐드(MakerCAD)로 4족 보행로봇을 3D 모델링하고 모션 프로그램과 연동했습니다. 모터 제어와 3D 로봇 모델이 함께 움직여, 실제 로봇을 켜기 전에 가상공간에서 걷는 모습을 먼저 확인합니다.

  1. 로봇 설계몸체·다리·브라켓을 3D로 설계하고 서보모터와 조립
  2. 모션 제작자세를 저장해 걷기·돌기·인사 동작 만들기
  3. 모터 제어관절마다 모터 ID를 연결하고 AX 서보 값(0~1023)으로 제어
  4. 가상 보행 시뮬레이션바닥 걷기로 3D 모델이 실제처럼 걸어가는 모습 확인

CERTIFICATE TUTORIAL · 3D프린터운용기능사

3D프린터운용기능사 실기,
튜토리얼로 따라 하기

공개문제의 실기 순서 그대로 연습합니다. 도면을 읽고 메이커캐드(MakerCAD)로 부품을 모델링·조립한 뒤 STP·STL로 저장하고, 슬라이싱과 출력, 후처리까지 한 번에 익힙니다.

과제 13D 모델링 작업
  1. 도면 읽기 · 부품 모델링도면대로 1:1 척도로 부품을 그립니다. 움직이는 부위의 끼워맞춤 여유를 정하고, 지정 위치에 비번호를 음각으로 새깁니다.체크: 기준치수 ±1mm 이내
  2. 어셈블리 · 파일 저장부품을 도면의 조립 상태 그대로 1:1로 조립하고 STP와 STL로 저장합니다. 파일명은 비번호(예: 02.STP)입니다.체크: 채점은 STP 파일 기준
  3. 슬라이싱시험장 프린터 기종에 맞춰 조립 상태로 슬라이싱하고, 예상 출력시간을 확인받습니다.체크: 예상 출력시간 1시간 20분 이내
과제 23D 프린팅 작업
  1. 프린터 세팅노즐과 베드의 이물질을 치우고 PLA 필라멘트를 점검한 뒤 베드 레벨링을 합니다.체크: 샘플 출력 테스트 불가
  2. 출력USB·SD 카드로 출력 파일을 직접 넣고, 설정값을 정해 1:1 조립 상태로 출력합니다.체크: 무선 전송 사용 불가
  3. 후처리 · 정리서포트와 거스러미를 제거해 제출하고, 프린터를 시험 전 상태로 정리합니다.체크: 보호장갑·방진마스크 착용
